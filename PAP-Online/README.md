# PAP Online — protótipo navegável

## Como executar
1. Extraia a pasta `PAP-Online`.
2. Abra `index.html` no navegador (ou use a extensão Live Server no VS Code).
3. Use os links de cadastro e recuperação de senha. Na área profissional, navegue pelo menu lateral.

## Telas
- Login: `index.html`
- Cadastro: `cadastro.html`
- Recuperar senha: `recuperar-1.html`, `recuperar-2.html`, `recuperar-3.html`
- Profissional: `profissional-inicial.html`, `profissional-agenda.html`, `profissional-mensagens.html`, `profissional-solicitacoes.html`, `profissional-perfil.html`

## Observação
Este é um protótipo front-end. Login, cadastro, envio de código, persistência e ações profissionais estão simulados no navegador. Para uso real, conecte uma API/backend e implemente autenticação, autorização e proteção de dados.
