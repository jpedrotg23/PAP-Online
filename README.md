## Demonstração

🌐 **[Acessar o frontend publicado](https://jpedrotg23.github.io/PAP-Online/)**

O projeto está em desenvolvimento. O que está publicado atualmente é um protótipo navegável de frontend. O backend em Java, Spring Boot e Spring Web ainda será desenvolvido pela equipe responsável.

## Objetivo

Centralizar informações e fluxos de acesso ao apoio psicopedagógico, aproximando estudantes e profissionais e facilitando a visualização de serviços, solicitações e atendimentos.

## Áreas representadas no protótipo

- **Estudante:** acesso ao ambiente do aluno, solicitações, agendamentos e acompanhamento.
- **Profissional:** área de trabalho com agenda e solicitações.
- **Administrador:** telas de gestão e acompanhamento.

O frontend também contém telas demonstrativas para fluxos como cadastro, recuperação de acesso, mensagens, histórico, notificações, relatórios e solicitações de adaptação acadêmica.

> **Importante:** essas telas representam fluxos da interface. Como o backend ainda não foi implementado, o protótipo não oferece autenticação real, persistência de dados nem operações institucionais reais. Não insira dados pessoais ou sensíveis na demonstração.

## Executar o frontend localmente

1. Clone o repositório:

```bash
git clone https://github.com/jpedrotg23/PAP-Online.git
cd PAP-Online
```

2. Abra a pasta `PAP-Online/` no VS Code.
3. Abra o arquivo `index.html` com uma extensão de servidor local, como Live Server.

Não é necessário instalar dependências Node.js para visualizar o frontend estático.
